**ZenAIList** is a real-time, velocity-based leaderboard for open-source AI projects. It tracks GitHub stars, deployment types, and hardware requirements for the fastest-growing LLMs, Agents, and RAG tools.

## 🚀 Why ZenAIList?
The standard GitHub trending page is noisy. Finding the breakout AI models, autonomous agents, and inference frameworks early is difficult. ZenAIList aggregates AI-specific data:

- **Velocity Tracking:** Real-time 1-day and 7-day star growth to detect breakout tools early.
- **Hardware Specs Context:** Identifies if a repository requires GPU inference or runs on Serverless environments.
- **1-Click Deployment:** Built-in templates to immediately deploy GPU-heavy projects to [RunPod](https://runpod.io?ref=0buvdumi) or serverless apps to Railway.

## 📊 Data & Ranking Methodology
Data is refreshed autonomously every hour. 
* Datasets are provided in raw JSON inside the `/data` folder for AI Agents and researchers.
* We analyze GitHub stargazers, developer velocity, and dependency trees to categorize projects into: `AI Agents`, `LLM Models`, `RAG Infrastructure`, and `Prompt Engineering`.
